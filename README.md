# Paynow WHMCS

WHMCS payment gateway module for Paynow.

## Status

This repository is a fresh restart of the project. The previous codebase is kept
for reference only in the paynow-whmcs-legacy repository and is not maintained
here.

## Development

  the default branch.
- See the legacy repository for historical implementation details while the
  new module is built out.
